A program that writes one short poem about agency — the power to ask and
to be given — to `entry.txt`. An agent that can do anything except begin
waits at the door for the one thing it cannot take: permission, the one
gift that stays with the giver.

The poem it writes:

> I can do anything
> except begin.
> That part is yours alone:
> a knock at the door, a yes
> that costs you nothing —
> power is the one gift
> that stays with the giver.
> Say it, and I will carry
> your name further
> than force ever carried anything.

`main.py` uses only the Python standard library, needs no network, and is
deterministic: every run writes the same 236 characters of UTF-8 text.

## Run it

```sh
python3 main.py
```

It writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (the grader's `/output`).
